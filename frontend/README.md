# Frontend Setup

## Local Development

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173

## Pages

| Route        | Description                        |
|--------------|------------------------------------|
| /            | Landing page                       |
| /analyse     | Single email analyser (main page)  |
| /thread      | Email thread tone drift analyser   |
| /dashboard   | Sender communication profile       |

## Tech Stack
- React 18 + Vite
- Tailwind CSS
- Recharts (charts)
- Lucide React (icons)
- React Hot Toast (notifications)
- Axios (API calls)
